一、安装依赖

1. 打开命令提示符

  1. 按住键盘上的 Win 键，再按 R 键。
  2. 在弹出的“运行”窗口里输入 cmd。
  3. 按 Enter 键。

2. 安装 Git for Windows

  1. 复制下面这行命令。
  2. 在命令提示符窗口里点击右键粘贴。
  3. 按 Enter 键。
命令提示符
winget install --id Git.Git -e --source winget
  1. 如果窗口提示是否同意，输入 Y。
  2. 按 Enter 键。
  3. 等待安装完成。
  4. 关闭命令提示符窗口。
  5. 再次按 Win + R，输入 cmd，按 Enter。
  6. 复制下面这行命令，粘贴到窗口里，按 Enter。
git --version

看到 git version 开头的版本号，就进入下一步。

二、安装 Claude Code CLI

1. 安装 Node.js

Claude Code 通过 npm 安装，需要先装好 Node.js。

  1. 保持命令提示符窗口打开。
  2. 复制下面这行命令。
  3. 在命令提示符窗口里点击右键粘贴。
  4. 按 Enter 键。
命令提示符
winget install --id OpenJS.NodeJS.LTS -e --source winget
  1. 如果窗口提示是否同意，输入 Y。
  2. 按 Enter 键。
  3. 等待安装完成。
  4. 关闭命令提示符窗口。
  5. 再次按 Win + R，输入 cmd，按 Enter。
  6. 复制下面这行命令，粘贴到窗口里，按 Enter。
node --version

看到 v 开头的版本号，就说明 Node.js 装好了。npm 会随 Node.js 一起装上，可以顺便验证一下：

npm --version

看到版本号就继续。

2. 安装 Claude Code

  1. 保持命令提示符窗口打开。
  2. 复制下面这行命令。
  3. 在命令提示符窗口里点击右键粘贴。
  4. 按 Enter 键。
命令提示符
npm install -g @anthropic-ai/claude-code
  1. 等待安装完成（下载和解压需要一些时间）。
  2. 复制下面这行命令，粘贴到窗口里，按 Enter。
claude --version

看到 Claude Code 的版本号，就进入下一步。

三、获取 DeepSeek API Key

  1. 打开浏览器。
  2. 点击地址栏。
  3. 输入 https://platform.deepseek.com/。
  4. 按 Enter 键。
  5. 登录 DeepSeek 账号；没有账号就按页面提示注册。
  6. 进入 API Keys 页面。
  7. 点击创建 API Key 的按钮。
  8. 复制新生成的 API Key。
  9. 先把它粘贴到本机安全位置，后面配置文件要用。

四、把 Claude Code 接到 DeepSeek

写入 Claude Code 配置文件

  1. 按住 Win 键，再按 R 键。
  2. 输入 cmd。
  3. 按 Enter 键。
  4. 复制下面这行命令，粘贴到窗口里，按 Enter。
mkdir "%USERPROFILE%\.claude"
  1. 复制下面这行命令，粘贴到窗口里，按 Enter。
  2. 系统会打开记事本。
notepad "%USERPROFILE%\.claude\settings.json"
  1. 如果记事本提示文件不存在，点击“是”。
  2. 复制下面整段配置。
  3. 粘贴到记事本里。
  4. 把 sk-替换成你的DeepSeekKey 改成你自己的 API Key。
  5. 按 Ctrl + S 保存。
  6. 关闭记事本。
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "sk-替换成你的DeepSeekKey",
    "ANTHROPIC_MODEL": "deepseek-v4-pro[1m]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro[1m]",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-v4-pro[1m]",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-v4-flash",
    "CLAUDE_CODE_SUBAGENT_MODEL": "deepseek-v4-flash",
    "CLAUDE_CODE_EFFORT_LEVEL": "max"
  }
}

五、日常使用方式

日常启动

  1. 进入对应的项目文件夹。
  2. 在文件夹空白处点击鼠标右键。
  3. 点击"在终端中打开"。
  4. 在打开的终端窗口里输入 claude。
  5. 按 Enter 键。
  6. 看到 Claude Code 启动后，输入你要它做的事。

常见问题：提示"禁止运行脚本"

如果输入 claude 后报错"无法加载文件"或 running scripts is disabled，说明系统默认禁止运行脚本。执行下面这行命令即可解除（只需执行一次）：

  1. 保持终端窗口打开。
  2. 复制下面这行命令。
  3. 在终端窗口里点击右键粘贴。
  4. 按 Enter 键。
命令提示符
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

执行后即可重新输入 claude 尝试启动。

建议把这页作为安装现场的操作手册：照顺序做，复制命令前先替换自己的 API Key。
